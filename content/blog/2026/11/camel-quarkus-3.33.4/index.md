We are pleased to announce the 3.33.4 LTS release of Camel Quarkus.

Camel Quarkus 3.33.4 aligns with the Camel 4.18.5 LTS and Quarkus 3.33.4.1 LTS releases.

For more information, please check the [Release notes](/releases/q-3.33.4/).

## Camel 4.18.5

Please refer to the [Camel 4.18.5 release announcement](/blog/2026/10/RELEASE-4.18.5/) for more details.

## Quarkus 3.33.4.1

You can find the Quarkus 3.33.4.1 release announcement on the [Quarkus Blog](https://quarkus.io/blog/quarkus-3-33-4-1-released/).

## Quarkus 3.33.4.2

Following the Camel Quarkus 3.33.4 release, Quarkus 3.33.4.2 was published to address further CVEs. Camel Quarkus 3.33.4 users are encouraged to upgrade their Quarkus version to 3.33.4.2.

You can find the Quarkus 3.33.4.2 release announcement on the [Quarkus Blog](https://quarkus.io/blog/quarkus-3-33-4-2-released/).

## Quarkus 3.33.5

Quarkus 3.33.5 is currently scheduled for release on December 2nd. The `quarkus-camel-bom` in this release will be aligned with Camel Quarkus 3.33.4.

Keep a watch on the Quarkus release announcements for more details.
