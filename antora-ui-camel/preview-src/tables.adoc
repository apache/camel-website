Every table is wrapped in a `div.table-wrapper` by `extensions/table.js`, which is what gives wide tables their horizontal scrollbar instead of letting them overflow the page.
The preview registers the same postprocessor, so the markup here matches the built site.

== Component options

The common case in Camel documentation: a reference table of endpoint options.

.Timer component, endpoint options
[%autowidth]
|===
|Name |Type |Default |Description

|`period`
|long
|1000
|Delay in milliseconds between firings.

|`repeatCount`
|long
|0
|Number of firings before the timer stops. Zero means unlimited.

|`fixedRate`
|boolean
|false
|Schedule at a fixed rate rather than a fixed delay.

|`includeMetadata`
|boolean
|false
|Add timer metadata headers to the exchange.
|===

== Formatted cells

An `a` column modifier lets a cell hold block content: lists, source, or an admonition.

|===
|Option |Detail

|`bridgeErrorHandler`
a|
Routes consumer-side exceptions into the route's error handler instead of logging and ignoring them.

[source,java]
----
from("file:inbox?bridgeErrorHandler=true")
    .to("direct:process");
----

|`synchronous`
a|
[NOTE]
====
Forces the exchange onto the calling thread. Rarely needed outside tests.
====

|`lazyStartProducer`
a|
* defers producer creation to the first message
* lets a route start while its target is unavailable
* moves the failure from startup to runtime
|===
